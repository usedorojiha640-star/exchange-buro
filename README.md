# EXCHANGE BURO PAY — готовый лендинг

Адаптивный одностраничный сайт на **React + Vite**. Полностью локальные SVG-иллюстрации: логотип с прозрачным фоном, глобус с монетами, четыре уникальных изображения преимуществ, карта мира и анимированный блок 24/7.

## Как запустить в VS Code (Windows)

1. Распакуйте ZIP, откройте в VS Code папку `exchange-buro-pay-website` (ту, где лежит `package.json`).
2. Выберите сверху **Terminal → New Terminal**.
3. По очереди выполните:

   ```powershell
   npm install
   npm run dev
   ```

4. Откройте адрес из терминала, обычно `http://localhost:5173/`.
5. Чтобы остановить сервер, нажмите `Ctrl + C`.

## Что настроить

- **Telegram менеджера:** `src/config.js`, константа `TELEGRAM_URL`.
  - По умолчанию указан `https://t.me/exchange_buro` — публичная ссылка с исходного exchangeburo.com.
  - Все кнопки ссылаются на эту константу.
- **Тексты и секции:** `src/App.jsx`.
- **Цвета, адаптив и анимации:** `src/styles.css`.
- **Логотип с прозрачным фоном:** `public/assets/logo.svg` — это вектор, его можно масштабировать без потерь.
- **Карта мира:** `public/assets/world-network.svg`. Точки служат иллюстрацией мировых городов, а не перечнем действующих офисов.
- **Фавикон:** `public/favicon.svg`.

## Публикация

Проверьте сборку:

```powershell
npm run build
```

На Vercel или Cloudflare Pages можно импортировать GitHub-репозиторий. Настройки:
- **Framework:** Vite
- **Build command:** `npm run build`
- **Output directory:** `dist`

Никакой сервер и API для лендинга не нужны: после сборки это статический сайт.

## Важные замечания

- Цифры о количестве клиентов и процентах успешных сделок не используются: они не подтверждены источниками.
- География и точки на карте носят иллюстративный характер, они не утверждают наличия офисов в конкретных городах.
- Сайт не содержит платежной логики или самостоятельного механизма проведения обмена. Все обращения перенаправляются в Telegram.
